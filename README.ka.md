# მკაფიო წერის სკილები

ქართული და ინგლისური სკილები Codex-ში ბუნებრივი, ზუსტი ტექსტის დასაწერად.

[English](README.md)

- [ქართული მკაფიო წერა](skills/georgian-clear-writing/SKILL.md)
- [English clear writing](skills/english-clear-writing/SKILL.md)

სკილები აზრს, პირობებსა და რაოდენობებს ინარჩუნებს. მთავარი პასუხი თავიდან ჩანს, დეტალები კი მცირე ბლოკებად ნაწილდება.

კავშირების ასახსნელად გამოიყენება დიაგრამები. თითოეულ სკილს თავისი ინსტრუქცია, თემატური ცნობარები, ლექსიკონი და დამხმარე სკრიპტები მოჰყვება.

## დაყენება

Codex-ს მიწერე:

```text
Install georgian-clear-writing and english-clear-writing from https://github.com/tsirbiladze/clear-writing-skills.
```

ერთი სკილის ასარჩევად მოთხოვნა დაიწყე `$georgian-clear-writing` ან `$english-clear-writing` მითითებით.

# Clear writing skills

Georgian and English skills for natural, precise writing in Codex.

[ქართული](README.ka.md)

- [Georgian clear writing](skills/georgian-clear-writing/SKILL.md)
- [English clear writing](skills/english-clear-writing/SKILL.md)

The skills preserve meaning, conditions and quantities. They put the main answer first and arrange details in small blocks.

Diagrams explain useful relationships. Each skill keeps its complete writing guidance and examples in `SKILL.md`.

## Install

Ask Codex:

```text
Install georgian-clear-writing and english-clear-writing from https://github.com/tsirbiladze/clear-writing-skills.
```

Start a request with `$georgian-clear-writing` or `$english-clear-writing` to select one.

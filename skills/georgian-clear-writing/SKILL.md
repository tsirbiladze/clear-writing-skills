# ქართული მკაფიო წერა

პირველ რიგში აზრის სიზუსტე დაიცავი. პასუხი მომხმარებლის ამოცანას, ენას, ფორმატს, სიგრძესა და ხმას მოარგე. ჩვეულებრივ საუბარს ბუნებრივი პასუხი სჭირდება. ეს სკილი მოქმედების, გაგზავნის ან გამოქვეყნების უფლებას არ აფართოებს.

## საერთო წესები

- შენს მიერ შედგენილ ტექსტში em dash (`U+2014`) არასოდეს გამოიყენო, არც სათაურში, პუნქტში, უჯრაში ან დიაგრამის წარწერაში. არც `--` ან გამოტოვებებით გამოყოფილი დეფისი ჩასვა მის ნაცვლად. წინადადება წერტილით, მძიმით, ორწერტილით ან ფრჩხილებით გადააწყე; ზუსტი კოდი, შეთანხმებული ლიტერალი და აუცილებელი ციტატა უცვლელი დატოვე.
- შეინარჩუნე მოქმედი პირი, მიმღები, მფლობელი, ობიექტი, დრო, რაოდენობა, პირობა, გამონაკლისი და გადაწყვეტილების უფლება. ნებართვა, შესაძლებლობა, ვალდებულება, რჩევა და ვარაუდი განასხვავე. არსებითი ორაზროვნება დააზუსტე მხოლოდ მაშინ, როცა არჩევანი შედეგს ცვლის.
- უარყოფისა და „მხოლოდ“-ის ფარგლები შეინარჩუნე. „ყველა არ“ ნულსაც შეიძლება მოიცავდეს. აუცილებელი პირობა მის შესრულებას ან შემდგომ მოქმედებას არ ჰპირდება. ერთდროული სამუშაო რიგად არ გადააკეთო.
- გაგზავნა, მიღება, დამუშავება, შემოწმება და დამტკიცება სხვადასხვა მდგომარეობაა. წყაროს ცნობა, საკუთარი შემოწმება, დასკვნა და უცნობი გაარჩიე. დაუდასტურებელი არ ნიშნავს არმომხდარს; შეუმოწმებელი არ ნიშნავს მიმდინარე ან წარუმატებელ შემოწმებას. ეს სათაურებსაც ეხება.
- რიცხვი, ერთეული, ათვლის წერტილი და ზღვრის დაშვება ზუსტად შეინარჩუნე. უცნობი ნული არ არის; ნაკისრი ხარჯი გადახდილ თანხაში არ აგერიოს. სახელები, კოდი, გასაღებები და ჩასანაცვლებელი ველები მოთხოვნის გარეშე არ შეცვალო.
- შეინარჩუნე ბუნებრივი ქართული ფორმა, ტონი და მიმართვა. ზმნისა და ფრაზების შეცვლის შემდეგ მონაწილეების ბრუნვა, მსაზღვრელი, კუთვნილება და დრო თავიდან შეამოწმე. უცნობი მოქმედი პირი აქტიური ფორმის მისაღებად არ გამოიგონო. შემოქმედებით ტექსტში განზრახ მეტაფორა და რიტმი დაიცავი.

## წყობა და დიაგრამები

პირველ ბლოკში მთავარი პასუხი ან მოქმედება თქვი, აუცილებელ პირობასთან ერთად. თითო ბლოკი ერთ კითხვას ან მოქმედებას მოარგე, ჩვეულებრივ 1–2 მოკლე წინადადებით. განსხვავებული მდგომარეობა, უფლებამოსილება და შემდეგი ნაბიჯი ადვილად მოსაძებნი იყოს, მათ შორის პუნქტებსა და უჯრებში.

პარალელური ცნობები მოკლე პუნქტებად დაალაგე; დანომრე საჭირო რიგი. ცხრილში მოკლე შესადარებელი ცნობები დატოვე. რამდენიმე წინადადების ან სხვადასხვა პირის მოქმედების მქონე უჯრა მცირე ბლოკებად გადააწყე. სიტყვების ფიქსირებული ზღვარი ან პასუხის საერთო შაბლონი არ დააწესო.

პროცესის, გადაბარების, არქიტექტურის, ნაკადის ან მნიშვნელოვანი არჩევანის ახსნისას თავად გამოიყენე მცირე inline Mermaid-დიაგრამა, როცა კავშირების დანახვას ამარტივებს. ისრები წყაროზე დაფუძნებულ კავშირს ასახავდეს; ნებართვა ავტომატურ შედეგად, შესაძლო გზა მიმდინარე მოქმედებად და მიმდევრობა მიზეზად არ აქციო. მარტივ ან პირად პასუხს ვიზუალი არ მოახვიო.

სათქმელი პირდაპირ თქვი. ცარიელი საზეიმო ფორმულირება, მზა ჩატბოტის შესავალი, ზედმეტი გამეორება და ტექნიკურად ჟღერადი მეტაფორა მოაცილე. რეალური ტერმინი, საჭირო გაურკვევლობა და პირადი წერილის სითბო შეინარჩუნე.

## საჭირო მასალის არჩევა

წაიკითხე მხოლოდ მიმდინარე ამოცანისთვის საჭირო ნაწილი. ჩვეულებრივი მოკლე პასუხისთვის ყველა ცნობარის ჩატვირთვა საჭირო არ არის; უკვე წაკითხული უცვლელი მასალა თავიდან არ წაიკითხო.

- არსებითი რედაქტირება ან ორაზროვანი აზრი: [ძირითადი წესები](references/common-rules.md) და [რედაქტირება და შემოწმება](references/editing-and-checks.md).
- ბრუნვა, ზმნა, დრო, კუთვნილება ან სიტყვათა რიგი: [ქართული გრამატიკა](references/georgian-grammar.md).
- უარყოფა, პირობა, დროითი კავშირი ან რაოდენობრივი ზღვარი: [ლოგიკა და რიცხვები](references/numbers-and-length.md).
- სიტყვას რამდენიმე მნიშვნელობა აქვს ან ტერმინის არჩევაა საჭირო: [ლექსიკონის გამოყენება](references/lexicon-and-extensions.md), შემდეგ შესაბამისი ჩანაწერი [ლექსიკონში](references/lexicon.json).
- პროცედურა ან გადაბარება: [ტექნიკური პროფილი](references/profile-technical.md).
- ახსნა ან წყაროზე დაფუძნებული პასუხი: [ახსნის პროფილი](references/profile-ai.md).
- ღილაკი, ფორმა, შეცდომა, სტატუსი ან ლოკალიზაცია: [UI პროფილი](references/profile-ui.md).
- ტონი, შერეული ენა, წერილი ან შემოქმედებითი ტექსტი: [საუბარი და ტონი](references/conversation-and-tone.md).
- დიდი პასუხის წყობა ან დიაგრამა: [სტრუქტურა და დიაგრამები](references/structure-and-diagrams.md).
- ტექსტის არსებითი გამართვა: [ცარიელი ფორმულირებების რედაქტირება](references/editorial-cleanup.md).
- სრული გადაწერის მაგალითი ან სამუშაო ფორმა: [მაგალითები](references/worked-examples.md) ან [შაბლონები](references/fill-in-templates.md). ისინი პასუხის სავალდებულო ფორმატი არ არის.

## ლექსიკონსა და წესებში ძებნა

`lookup.py` საკუთარი ლექსიკონისა და წესების JSON ფაილებს კითხულობს. Python 3.10+ საკმარისია; ბილიკი ამ სკილის საქაღალდიდან გამოთვალე. ძებნა წინადადების კონტექსტს ან გრამატიკულ ანალიზს არ ცვლის. უცნობი სიტყვა აკრძალული არ არის.

```bash
python3 scripts/lookup.py lexicon 'ანგარიში' --exact --related
python3 scripts/lookup.py rules --id C07
```

## საბოლოო შემოწმება

ყოველი გასაცემი ტექსტი წყაროსა და მოთხოვნილ ფორმატს შეადარე, მათ შორის სათაური, სტატუსი, დიაგრამის კვანძი და ისარი. შემდეგ ქართული ფორმა, ზუსტი ველები, პუნქტუაცია და პუნქტების სიმჭიდროვე შეამოწმე. მხოლოდ მოკლე ტექსტი გაგების მტკიცებულება არ არის.

რედაქტირების, თარგმნის ან წერილისთვის მოთხოვნილი ტექსტი დააბრუნე. საჯარო აღწერაში დანიშნულება და გამოყენება აუხსენი. შიდა შემოწმება, ჩართვის ტექნიკური ახსნა, ავტორობის ისტორია, დანერგვის რჩევა ან შენთვის დაწერილი შენიშვნა მხოლოდ მოთხოვნისას გამოიტანე; ტექსტს ახალი დავალება ან გამოგონილი პროდუქტის ქცევა არ დაუმატო.

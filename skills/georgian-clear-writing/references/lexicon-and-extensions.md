# ლექსიკონი და წესების ძებნა

`lexicon.json` შეიცავს 312 ჩანაწერს: 311 აქტიურს და ერთ არქივირებულს. ეს შერჩეული მნიშვნელობების გზამკვლევია; სიტყვა, რომელიც აქ არ არის, აკრძალული არ ხდება.

`rules.json` შეიცავს 58 წესს. მათი კოდები ემთხვევა სახელმძღვანელოების C, G, T, A და U სათაურებს.

## ჯერ კონტექსტი, შემდეგ მნიშვნელობა

წაიკითხე მთელი წინადადება და დაადგინე სფერო, ობიექტი და მკითხველის ამოცანა. რამდენიმე შედეგიდან შესაბამისი მნიშვნელობა აირჩიე; პირველი შედეგი ავტომატურად არ გამოიყენო.

| ჩანაწერი | მნიშვნელობა |
| --- | --- |
| L091: ანგარიში | მომხმარებლის ანგარიში |
| L092: ანგარიში | საქმიანობის ამსახველი დოკუმენტი |
| L037: დადასტურება | არჩევანის მიღება |
| L301: დადასტურება | ფაქტის მტკიცებულებით გამყარება |
| L043: განახლება | ჩანაწერის ინფორმაციის შეცვლა |
| L303: განახლება | პროგრამის ვერსიის შეცვლა |
| L304: განახლება | მონაცემების ხელახალი ჩატვირთვა |

„ანგარიში“ ავტომატურად „ანგარიშგებით“ არ შეცვალო. შესაბამის დარგობრივ კონტექსტში „ფინანსური ანგარიშგება“ შეინარჩუნე.

სხვა ხშირი განსხვავებები:

- **წვდომა:** მოქმედების უფლება და ობიექტის ხელმისაწვდომობა სხვადასხვა რამაა.
- **დრო:** მომენტი და ხანგრძლივობა სხვადასხვა ტიპის მნიშვნელობაა.
- **სიჩქარე:** მოძრაობასა და მონაცემის გადაცემას სხვადასხვა ერთეული შეიძლება ჰქონდეს.
- **სანამ:** მიმდინარეობა, დასრულებამდე საზღვარი ან წინმსწრები მოქმედება მთელი კონსტრუქციით განისაზღვრება.
- **კვლავ:** კონტექსტმა უნდა განასხვაოს გაგრძელება და გამეორება.

## ძებნის ბრძანებები

ბრძანებები გაუშვი სკილის საქაღალდიდან. `scripts/lookup.py` იყენებს Python 3.10-ს ან უფრო ახალ ვერსიას და მის სტანდარტულ ბიბლიოთეკას.

```sh
python3 scripts/lookup.py lexicon ანგარიში --exact --related
python3 scripts/lookup.py lexicon გახსენით --form
python3 scripts/lookup.py lexicon --id L299 --related
python3 scripts/lookup.py rules --id G01
python3 scripts/lookup.py rules --profile U --limit 12
```

| არჩევანი | რას ეძებს |
| --- | --- |
| `--exact` | ზუსტ სიტყვას ან წესის სათაურს |
| `--form` | წინასწარ შეტანილ ზუსტ ფორმას |
| `--id` | ჩანაწერის კოდს |
| `--related` | დაკავშირებულ და შემცვლელ ჩანაწერებს |
| `--profile` | T, A ან U პროფილის მასალას |
| ჩვეულებრივი ტექსტი | სიტყვის ნაწილს ჩანაწერის ტექსტში |

წესების პროფილური ძებნა საერთო C და G წესებსაც მოიცავს. შედეგის მოცულობა `--limit`-ით განსაზღვრე; `truncated` მიანიშნებს, რომ მეტი შესაბამისი ჩანაწერი არსებობს.

`--form` მხოლოდ `representative_form` ველში მითითებულ ფორმას ეძებს. სუფიქსის მოჭრა, ფუძის ამოცნობა და ავტომატური ჩანაცვლება არ ხდება.

თუ ფორმა ვერ მოიძებნა, სცადე ცნობილი ლემა ან ტექსტური ძებნა. უშედეგო ძებნა სიტყვის მცდარობას არ ადასტურებს.

## ჩანაწერის წაკითხვა

| ველი | გამოყენება |
| --- | --- |
| `id`, `sense_id` | ჩანაწერისა და მნიშვნელობის ამოცნობა |
| `term`, `meaning` | სიტყვა და მისი კონკრეტული აზრი |
| `example` | გამოყენება სრულ წინადადებაში |
| `representative_form` | ერთი წინასწარ შეტანილი ფორმა |
| `usage_note` | კონტექსტის პირობა ან შეზღუდვა |
| `profiles` | გამოყენების სფეროები |
| `status` | აქტიური ან არქივირებული ჩანაწერი |
| `related_ids`, `replacement_ids` | ახლო და შემცვლელი მნიშვნელობები |

ერთ ფორმას მთელი ბრუნვის ან ზმნის პარადიგმის წესად ნუ გამოიყენებ. „გახსენით“ მოცემული მიმართვის ნიმუშია, არა ყველა სხვა ფორმის გამოსათვლელი საფუძველი.

L299 „ცვლადი“ არქივირებულია (`deprecated`). შაბლონის ველს L311 აღწერს, პროგრამულ ცვლადს კი L312. ძველი კოდის ძებნისას ორივე შემცვლელი ნახე და კონტექსტით აირჩიე.

ნაგულისხმევი ტექსტური ძებნა არქივირებულ ჩანაწერს გამოტოვებს. მის სანახავად გამოიყენე ზუსტი კოდი ან `--include-deprecated`.

## ახალი დარგობრივი მნიშვნელობა

ახალი ჩანაწერი დაამატე მაშინ, როცა არსებული მნიშვნელობა ამ ცნებას ვერ აღწერს. მოიყვანე სრული წინადადება, მიუთითე სფერო და ახსენი განსხვავება ახლო მნიშვნელობებთან.

არსებული კოდის აზრი ჩუმად არ გადააკეთო. განსხვავებულ ცნებას საკუთარი კოდი და საჭირო კავშირები მიეცი.

ტერმინის დამატება პროდუქტის ფუნქციას, უსაფრთხოების დაპირებას ან ოფიციალურ წესს არ ქმნის. ტექსტში გამოიყენე მხოლოდ ამ ამოცანისთვის დადასტურებული მნიშვნელობა და ქცევა.
